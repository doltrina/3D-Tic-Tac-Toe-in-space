# 🌌 Cosmic 3D Tic-Tac-Toe (Космические 3D Крестики-Нолики)

> Футуристическая тактическая 3D-игра в космическом сеттинге на базе **Three.js** и **WebGL**, с поддержкой локального мультиплеера по сети (LAN) через WebSockets, умным ИИ и адаптивным управлением для ПК и мобильных устройств.

## ✨ Особенности игры

- 🛰 **Полноценное 3D пространство (3×3×3 = 27 ячеек)**: победные линии строятся по всем измерениям (горизонтали, вертикали, глубина и пространственные 3D-диагонали).
- 🪐 **Космическая графика**:
  - Анимированное процедурное звездное небо и шейдерные туманности.
  - Неоновые светящиеся фигуры, лазерные лучи при победе и частицы.
  - 3 галактические темы: *Неоновый Небула*, *Солнечная Вспышка*, *Аномалия Бездны*.
  - Выбор стиля фигур: *Кристалл & Сатурн* или *3D Крест & Тор*.
- 🔊 **Встроенный аудиосинтезатор (Web Audio API)**: процедурные космические звуковые эффекты лазеров, наведения и победы без внешних тяжелых аудиофайлов.
- 🌐 **Сетевой мультиплеер по LAN**:
  - Игра вдвоем через Wi-Fi/локальную сеть с ПК, ноутбуков, смартфонов и планшетов.
  - Мгновенное подключение со смартфона по **QR-коду** или короткому коду комнаты (например, `NOVA-42`).
  - Синхронизация ходов, побед, сброса раундов в реальном времени через WebSockets.
  - Тактический внутриигровой чат и анимированные космические эмодзи/сигналы (🚀, 💥, 🧠, ⚡, 👑, 🛸).
- 🤖 **Одиночные режимы**:
  - **1v1 на одном экране (Hotseat)**: дуэль за одним устройством.
  - **Против бота (Легкий)**: тренировочный дроид для знакомства с пространственной механикой.
  - **Квантовый ИИ (Хард)**: алгоритм с пространственной оценкой угроз, блокировкой линий противника и созданием вилок.
- ⚖ **Балансировка 3D-ядра**: опция блокировки центра куба (ячейка 13) для исключения гарантированного преимущества первого игрока.
- 👁 **Послойный просмотр**: фильтрация уровней куба по оси Z для легкого ориентирования в глубине.
- 📱 **Полная мобильная адаптация**: плавное сенсорное управление (вращение одним пальцем, зум щипком, быстрый тап без ложных срабатываний при вращении, тактильный виброотклик).

## 🚀 Быстрый старт

### 1. Требования
- Установленный [Node.js](https://nodejs.org/) (версия 14 или выше).

### 2. Установка
Клонируйте репозиторий и установите зависимости:
```bash
git clone https://github.com/ВАШ_ЛОГИН/krestiki_noliki_space_3D.git
cd krestiki_noliki_space_3D
npm install
```

### 3. Запуск

#### Вариант А: Одной кнопкой / Скриптом (автоматически установит зависимости при первом запуске)
- **Windows**: запустите `start-lan-game.bat` (двойным кликом).
- **macOS / Linux**: в терминале выполните:
  ```bash
  chmod +x start-lan-game.sh
  ./start-lan-game.sh
  ```

#### Вариант Б: Через терминал
```bash
npm start
```
*(Сервер автоматически определит ваш локальный IP-адрес и порт `3000`)*.

## 🎮 Как играть

1. Откройте в браузере:
   - На компьютере-хосте: `http://localhost:3000`
   - На других устройствах в домашней сети: `http://<IP_ХОСТА>:3000` (IP будет выведен в консоли при старте).
2. Выберите режим в главном меню:
   - **👥 На одном экране**: играйте вдвоем по очереди за одной клавиатурой/мышью.
   - **🌐 Игра по сети (LAN)**: создайте комнату и покажите QR-код другу, либо введите код комнаты.
   - **🤖 / 🧠 Против ИИ**: сразитесь с компьютером в 3D.

### Управление:
| Действие | ПК (Мышь / Клавиатура) | Смартфон / Планшет |
|---|---|---|
| **Сделать ход** | Клик ЛКМ по ячейке | Быстрый тап по ячейке |
| **Вращение поля** | Зажать ЛКМ и тянуть | Свайп одним пальцем |
| **Масштаб (Зум)** | Колесико мыши | Жест двумя пальцами (щипок) |
| **Панорама камеры** | Зажать ПКМ и двигать | Жест двумя пальцами со сдвигом |
| **Фильтр слоев** | Кнопка «👁 ВСЕ СЛОИ» | Кнопка «👁 ВСЕ СЛОИ» |

## 🛠 Стек технологий

- **Клиент**: HTML5, Vanilla CSS3 (киберпанк-стекломорфизм, неоновые эффекты), JavaScript (ES6+ Modules).
- **3D Движок**: [Three.js](https://threejs.org/) (r128) + `OrbitControls`.
- **Серверная часть**: Node.js HTTP-сервер (раздача статики и автоопределение сетевых интерфейсов).
- **Сетевой протокол**: WebSockets ([ws](https://github.com/websockets/ws)).
- **Звук**: Web Audio API (динамическая генерация сигналов).
